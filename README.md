# Sudoku Oyunu

Modern, mobil uyumlu bir Sudoku oyunu.

## Özellikler

- 9×9 tahta, 3×3 alt ızgaralar
- Kolay / Orta / Zor seviyeler
- Dokunmatik tuş takımı ve klavye desteği
- Canlı kural kontrolü (satır, sütun, kutu)
- Not (kalem) modu
- Yeni oyun, baştan başlat, kazanma ekranı

## Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini aç.

## Teknolojiler

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
